Mathematical Proofs for the G-F Consistency Framework
======================================================

This section provides formal propositions and theorems supporting the
Geometric-Functional (G-F) consistency framework for evaluating protein
interaction network embeddings.

Notation and Definitions
------------------------

Let X = {x_1, ..., x_N} in R^d be an embedding of N proteins. Let D be
the pairwise Euclidean distance matrix with D_{ij} = ||x_i - x_j||_2.
For a distance threshold r > 0, define the spatial graph G(r) = (V, E(r))
where V = {1, ..., N} and E(r) = {(i, j) : 0 < D_{ij} < r}.

Let C(r) = {C_1, ..., C_K} be the community partition obtained by greedy
modularity optimisation on G(r). Let T_v denote the set of GO terms
annotated to protein v.

The functional purity of a community C is:

    purity(C) = max_t |{v in C : t in T_v}| / |{(v, t) : v in C, t in T_v}|

The mean functional purity at threshold r is:

    P(r) = (1 / |C(r)|) * sum_{C in C(r)} purity(C)

The G-F Score over integration interval [r_min, r_max] is:

    GF(X) = (1 / (r_max - r_min)) * integral_{r_min}^{r_max} P(r) dr

The rescaling operator R_sigma maps coordinates to target standard
deviation sigma:

    R_sigma(X) = (sigma / std(X)) * X

where std(X) = sqrt((1/Nd) * sum_{i,k} X_{ik}^2) is the global standard
deviation of all coordinate entries.


Proposition 1 (Well-definedness and bounds of G-F purity).
----------------------------------------------------------
For any embedding X and any community C containing at least one annotated
protein, purity(C) in [0, 1]. Consequently, P(r) in [0, 1] for all r > 0,
and GF(X) in [0, 1] for any integration interval [r_min, r_max] with
r_max > r_min.

Proof.
  Let n_t(C) = |{v in C : t in T_v}| be the number of proteins in C
  annotated with GO term t. The set of active terms is T(C) =
  {t : n_t(C) > 0}. By definition:

    purity(C) = max_{t in T(C)} n_t(C) / sum_{t in T(C)} n_t(C)

  Since max_t n_t(C) >= n_{t'}(C) for any t' in T(C), and the denominator
  is the sum of all n_t(C) including the maximum term:

    max_t n_t(C) <= sum_t n_t(C)

  so purity(C) <= 1. Since n_t(C) >= 1 for all active terms, purity(C) > 0.
  For unannotated communities, purity(C) = 0 by convention, so purity(C)
  in [0, 1].

  P(r) is a mean of values in [0, 1], hence P(r) in [0, 1]. GF(X) is a
  normalised integral of P(r) over a positive-length interval; since
  P(r) in [0, 1], the integral is in [0, r_max - r_min], and dividing by
  (r_max - r_min) gives GF(X) in [0, 1].  QED


Proposition 2 (Rescaling is a uniform distance scaling).
--------------------------------------------------------
For any non-degenerate embedding X (std(X) > 0) and target sigma > 0,
let X' = R_sigma(X). For all i, j:

    ||x'_i - x'_j|| = (sigma / std(X)) * ||x_i - x_j||

Proof.
  X' = alpha * X where alpha = sigma / std(X) > 0. Then:

    ||x'_i - x'_j||^2 = sum_k (alpha * X_{ik} - alpha * X_{jk})^2
                       = alpha^2 * sum_k (X_{ik} - X_{jk})^2
                       = alpha^2 * ||x_i - x_j||^2

  Taking square roots (alpha > 0): ||x'_i - x'_j|| = alpha * ||x_i - x_j||.

  This is a uniform scaling: all pairwise distances are multiplied by the
  same factor alpha.  QED


Theorem 1 (G-F Score scale invariance under rescaling).
-------------------------------------------------------
Let X and X' = R_sigma(X) be two embeddings related by rescaling with
target standard deviation sigma > 0. Let alpha = sigma / std(X). Then:

  (a) P'(r) = P(r / alpha) for all r > 0, where P and P' are the G-F
      purity curves for X and X' respectively.

  (b) The G-F Score is covariant under joint rescaling: for any fixed
      integration interval [r_min, r_max],

      GF(X'; alpha * r_min, alpha * r_max) = GF(X; r_min, r_max)

      That is, rescaling the embedding by alpha and rescaling the
      integration interval by the same factor preserves the G-F Score.

Proof of (a).
  By Proposition 2, D'_{ij} = alpha * D_{ij}. An edge (i,j) exists in
  G'(r) iff 0 < D'_{ij} < r, which holds iff 0 < alpha * D_{ij} < r,
  which is equivalent to 0 < D_{ij} < r / alpha. This is precisely the
  edge condition for G(r / alpha). Therefore G'(r) = G(r / alpha) as
  graphs (same vertex set, same edge set).

  Greedy modularity optimisation is deterministic on connected graphs
  (Newman 2004); for disconnected G(r), the algorithm processes each
  component independently and we assume a fixed tie-breaking rule.
  Under this assumption, C'(r) = C(r / alpha). Purity depends only on
  community membership and GO annotations, so P'(r) = P(r / alpha).  QED

Note on the determinism assumption. Greedy modularity optimisation
(Newman 2004) processes node pairs in a data-dependent order and may
produce different community partitions when node ordering changes.
NetworkX's implementation (greedy_modularity_communities) uses a
fixed, deterministic ordering based on node labels, ensuring
reproducibility within the same library version. The scale-invariance
result (Theorem 1a) holds exactly when the same implementation and
node ordering is used for both X and X'. In practice, since rescaling
preserves the graph structure (same edges, same components), the
deterministic implementation produces identical partitions.  QED

Proof of (b).
  Using the trapezoidal rule with sample points s_1 < s_2 < ... < s_m
  in [alpha * r_min, alpha * r_max]:

    GF(X') = (1 / (alpha*(r_max - r_min))) * sum_{k=1}^{m-1}
              (s_{k+1} - s_k) * (P'(s_k) + P'(s_{k+1})) / 2

  Set s_k = alpha * r_k where r_k are equally spaced in [r_min, r_max].
  By part (a), P'(s_k) = P(s_k / alpha) = P(r_k). Substituting:

    GF(X') = (1 / (alpha*(r_max - r_min))) * sum_k
              alpha*(r_{k+1} - r_k) * (P(r_k) + P(r_{k+1})) / 2
           = (1 / (r_max - r_min)) * sum_k
              (r_{k+1} - r_k) * (P(r_k) + P(r_{k+1})) / 2
           = GF(X; r_min, r_max)

  The alpha factors cancel exactly.  QED

Practical corollary (pipeline convention).
  In the pipeline, all embeddings are rescaled to TARGET_STD = 0.3 before
  G-F curve computation, and the integration interval [r_min, r_max] is
  fixed. If X and Y differ only by a multiplicative scale factor (i.e.,
  X = c * Y for some c > 0), then R_sigma(X) = R_sigma(Y) identically,
  so they produce the same rescaled embedding and therefore the same G-F
  curve and score. More generally, part (b) shows that comparing two
  embeddings at different scales requires either rescaling both to a
  common sigma, or adjusting the integration interval accordingly.


Remark 1 (Subinterval decomposition of G-F Score).
----------------------------------------------------
This is a direct consequence of the linearity of integration.

Let a < c < b. The G-F Score over [a, b] decomposes as:

    GF([a,b]) = w_1 * GF([a,c]) + w_2 * GF([c,b])

where w_1 = (c - a) / (b - a) and w_2 = (b - c) / (b - a), with
w_1 + w_2 = 1 and w_1, w_2 > 0.

Corollary: min(GF([a,c]), GF([c,b])) <= GF([a,b]) <= max(GF([a,c]),
GF([c,b])).

Proof.
  By definition:

    GF([a,b]) = (1/(b-a)) * integral_a^b P(r) dr

  Splitting the integral at c:

    integral_a^b P(r) dr = integral_a^c P(r) dr + integral_c^b P(r) dr

  Substituting:

    GF([a,b]) = (1/(b-a)) * [(c-a) * GF([a,c]) + (b-c) * GF([c,b])]
              = ((c-a)/(b-a)) * GF([a,c]) + ((b-c)/(b-a)) * GF([c,b])
              = w_1 * GF([a,c]) + w_2 * GF([c,b])

  Since w_1, w_2 > 0 and w_1 + w_2 = 1, this is a convex combination.
  The corollary follows from the standard property that a convex
  combination of two values lies in their closed interval.  QED


Theorem 3 (Plateau width and G-F Score stability).
--------------------------------------------------
Let method m have plateau width W_m (relative threshold theta = 0.80)
and peak purity p*_m. If the integration interval [r_min, r_max] is fully
contained within the plateau region [r_plateau_min, r_plateau_max], then:

    GF_m >= theta * p*_m

Furthermore, for any two methods m_1 and m_2 with plateau regions
containing [r_min, r_max]:

    |GF_{m_1} - GF_{m_2}| <= |p*_{m_1} - p*_{m_2}|
                              + (1 - theta) * max(p*_{m_1}, p*_{m_2})

Proof.
  Within the plateau, P(r) >= theta * p*_m for all r in [r_plateau_min,
  r_plateau_max]. If [r_min, r_max] is a subset of this region:

    GF_m = (1/(r_max - r_min)) * integral_{r_min}^{r_max} P(r) dr
         >= (1/(r_max - r_min)) * integral_{r_min}^{r_max} theta * p*_m dr
         = theta * p*_m

  For the second part, within both plateaus:

    theta * p*_{m_1} <= P_{m_1}(r) <= p*_{m_1}
    theta * p*_{m_2} <= P_{m_2}(r) <= p*_{m_2}

  To bound |P_{m_1}(r) - P_{m_2}(r)|, assume WLOG p*_{m_1} >= p*_{m_2}.
  Then:

    P_{m_1}(r) - P_{m_2}(r) <= p*_{m_1} - theta * p*_{m_2}
        = (p*_{m_1} - p*_{m_2}) + (1 - theta) * p*_{m_2}
       <= |p*_{m_1} - p*_{m_2}| + (1 - theta) * max(p*_{m_1}, p*_{m_2})

    P_{m_2}(r) - P_{m_1}(r) <= p*_{m_2} - theta * p*_{m_1}
        = (1 - theta) * p*_{m_1} - (p*_{m_1} - p*_{m_2})
       <= (1 - theta) * max(p*_{m_1}, p*_{m_2})

  Both cases give |P_{m_1}(r) - P_{m_2}(r)| <= |p*_{m_1} - p*_{m_2}| +
  (1 - theta) * max(p*_{m_1}, p*_{m_2}). Integrating and dividing by
  (r_max - r_min) yields the stated bound.  QED

  Practical implication: methods with wider plateaus have G-F Scores that
  are more robust to the choice of integration interval. The relative
  threshold theta = 0.80 ensures that plateau G-F Scores are at least
  80% of peak purity.


Theorem 4 (Random baseline convergence).
----------------------------------------
Note: The concentration inequality below is valid for individual community
purity, but the max-operation introduces selection bias that is not
formally bounded. The variance decomposition assumes inter-community
independence, which does not hold on spatial graphs. The result is best
understood as a large-N heuristic supported by empirical evidence
(10-permutation randomisation control, Z = 6.95).

Under a random permutation pi of node labels, the expected G-F purity at
threshold r converges to the uniform GO term purity:

    E_pi[P_pi(r)] -> p_unif   as N -> infinity

where p_unif = max_t f_t / sum_t f_t is the uniform purity computed from
the global GO term frequencies f_t = |{v : t in T_v}|.

Assumptions:
  (i) The community structure C(r) is unchanged by the permutation
      (distances are fixed; only labels are permuted).
  (ii) The minimum community size min_k |C_k(r)| -> infinity as N ->
       infinity. This holds when r grows with N so that communities
       contain a growing number of nodes. For fixed r on spatial
       graphs with bounded-density communities, some C_k may remain
       O(1) and the convergence is correspondingly weaker.

Furthermore, Var[P_pi(r)] = O(1/N), so the random baseline concentrates
around its expectation.

Proof.
  Under permutation pi, node pi(v) occupies position v in the embedding.
  Community C_k(r) (the k-th community) at threshold r depends only on
  embedding geometry (pairwise distances), which is unchanged by the
  permutation. The set of GO terms assigned to C_k(r) under pi is:

    T(C_k, pi) = union_{i in C_k} T_{pi(i)}

  Since pi is a uniformly random bijection, the multiset of GO terms in
  C_k(r) is a simple random sample (without replacement) of size |C_k(r)|
  from the global GO annotation multiset {T_1, ..., T_N}.

  For term t with global frequency f_t = |{i : t in T_i}|, the expected
  count in community C_k(r) is:

    E[n_t(C_k)] = f_t * |C_k(r)| / N

  For large N with |C_k(r)| -> infinity (Assumption ii), by the
  multivariate hypergeometric concentration (Chvatal 1979), n_t(C_k)
  concentrates around its mean:

    P(|n_t(C_k) - E[n_t]| > epsilon * |C_k|) <= 2 exp(-2 epsilon^2 |C_k|)

  Therefore purity(C_k) -> max_t (f_t * |C_k| / N) / (sum_t f_t * |C_k| / N)
                        = max_t f_t / sum_t f_t = p_unif

  as |C_k| -> infinity.

  The mean purity P_pi(r) = (1/K) sum_k purity(C_k) is an average of K
  such terms, each concentrating around p_unif. By standard variance
  bounds for sampling without replacement:

    Var[P_pi(r)] = O(1/K) + O(1/min_k |C_k|) = O(1/N)

  under Assumption (ii), since K >= 1 and community sizes grow with N.

  The G-F Score under permutation:

    GF_pi = (1/(b-a)) * integral_a^b P_pi(r) dr

  has expectation E[GF_pi] -> p_unif and Var[GF_pi] = O(1/N) by
  dominated convergence (P_pi(r) is uniformly bounded in [0, 1]).

  Note: For fixed r on spatial graphs where some communities remain
  small (|C_k| = O(1)), the concentration inequality above does not
  apply to those communities and the convergence rate is slower. In
  practice, the randomisation baseline (10 shuffles in the pipeline)
  provides an empirical estimate of p_unif that accounts for the
  actual community structure at the chosen r values.  QED


Proposition 3 (kNN-GF Score: high-dimensional generalisation).
----------------------------------------------------------------
Let X = {x_1, ..., x_N} in R^d be an embedding. For integer k >= 1,
define the symmetric k-nearest-neighbour graph G_k = (V, E_k) where
E_k = {(i, j) : j in kNN(i) or i in kNN(j)}, and kNN(i) denotes the
set of k nodes closest to i by Euclidean distance.

The kNN functional purity at parameter k is:

    P_kNN(k) = functional_purity(C(G_k), T)

where C(G_k) is the community partition of G_k. The kNN-GF Score over
[k_min, k_max] is:

    GF_kNN(X) = (1 / (k_max - k_min + 1)) * sum_{k=k_min}^{k_max} P_kNN(k)

Unlike the Euclidean GF Score (which depends on absolute distances via
the threshold r), the kNN-GF Score depends only on the *ranking* of
pairwise distances (order statistics), not their absolute values.


Theorem 5 (Distance concentration invariance).
-------------------------------------------------
Let X_d and X'_d be two embeddings in R^d related by a transformation
that preserves the ranking of all pairwise distances (i.e., a
monotone transformation of the distance function). Then:

    GF_kNN(X_d) = GF_kNN(X'_d)

for all d. In particular, the kNN-GF Score is invariant to the
concentration of distances (curse of dimensionality), which changes
absolute distances but preserves their ranking.

Proof.
  The kNN graph G_k depends only on which nodes are the k nearest
  neighbours of each node. A monotone transformation of distances
  preserves the ranking: if ||x_i - x_j|| < ||x_i - x_l|| before the
  transformation, the inequality still holds after. Therefore kNN(i)
  is unchanged, G_k is the same graph, C(G_k) is the same partition,
  and P_kNN(k) is identical. Since this holds for all k, GF_kNN is
  invariant.  QED

  Practical implication: as dimension d increases, pairwise Euclidean
distances concentrate (variance/mean -> 0, Beyer et al. 1999). This
inflates the Euclidean GF Score (Theorem 6) but does not affect the
kNN-GF Score, making the latter the correct metric for high-dimensional
embedding evaluation.


Theorem 6 (Euclidean GF Score inflation under distance concentration).
-----------------------------------------------------------------------
Let CV(d) = std(D_d) / mean(D_d) be the coefficient of variation of
pairwise distances D_d in dimension d. Under distance concentration
(CV(d) -> 0 as d -> infinity), the Euclidean GF Score is systematically
inflated:

    Corr(GF_euc(d), CV(d)) < 0

i.e., the Euclidean GF Score increases as distances concentrate.

Proof sketch.
  As CV(d) -> 0, all pairwise distances converge to the mean distance
  d_bar. For any threshold r >= d_bar, the spatial graph G(r) becomes
  the complete graph K_N (all pairs connected). Community detection on
  K_N produces a single community containing all N nodes, and the
  functional purity of this single community equals the global maximum
  GO term frequency — higher than the multi-community purity at lower
  d. Thus GF_euc increases as CV decreases.

  Numerical verification (Spectral embedding, d=2..64, 153-node yeast
  PPI): Spearman rho(GF_euc, CV) = -1.000 (p < 0.001), confirming
  perfect negative correlation. GF_euc rises from 0.163 (d=2, CV=0.81)
  to 0.267 (d=64, CV=0.11), a 64% inflation driven entirely by distance
  concentration, not by improved embedding quality.

  Corollary: the Euclidean GF Score cannot be used to compare embeddings
  at different dimensions. The kNN-GF Score (Theorem 5) is the correct
cross-dimensional metric.


Algorithm S1: G-F Curve Construction
-------------------------------------

Input:
  - Embedding coordinates for N nodes
  - GO annotation mapping for each node
  - Range of distance thresholds r = [0.05, 0.55] with step delta_r
  - Community detection algorithm A (greedy modularity optimisation)

Output:
  - G-F curves: purity(r), modularity(r)

Procedure:
1. Compute pairwise Euclidean distance matrix D (N x N)
2. For each r in r_range:
   a. Construct graph G(r) by adding edge (i,j) if D[i,j] < r and i != j
   b. Apply greedy modularity optimisation to G(r) to obtain communities
   c. Compute functional purity = mean over communities of
      (max GO term count / total GO terms in community)
   d. Compute Newman-Girvan modularity Q(r)
3. Plot purity(r) and Q(r) against r
4. Return curves


Algorithm S1b: IC-Weighted and Semantic Purity Variants
--------------------------------------------------------

To address two known limitations — (i) DAG expansion inflation (True Path
Rule adds ~5.5x ancestor terms, diluting count-based purity) and (ii) the
exact-match-only nature of standard purity — we provide two additional
purity variants as robustness checks.

IC-weighted purity. Each GO term is weighted by its Information Content
IC(t) = -log( freq(t) / N_genes ), computed from the full yeast genome
annotation corpus.  The IC-weighted purity of community C is:

    purity_IC(C) = max_t [count(t,C) * IC(t)] / sum_t [count(t,C) * IC(t)]

This down-weights non-specific ancestor terms (low IC) introduced by DAG
propagation.  Empirically, IC-weighted G-F scores correlate rho = +0.964
(P < 0.001) with standard scores across 11 methods, confirming rank
preservation, while the DAG inflation ratio drops from 0.78 to 0.21.

Semantic purity (Resnik MICA).  Pairwise GO term similarity is computed
via Resnik's Most Informative Common Ancestor (MICA) method using the full
GO DAG (24,136 BP terms from go.obo release 2026-05-19).  The semantic
purity of community C is:

    purity_sem(C) = (2 / (n*(n-1))) * sum_{i<j} sim_norm(t_i, t_j)

where sim_norm(t_i, t_j) = IC(MICA(t_i, t_j)) / max_IC is normalised to
[0, 1].  This captures functional coherence based on GO DAG topology:
communities with semantically related (but non-identical) terms score high.

Spearman correlations between variants (n = 11 methods, original annotations):

    Standard vs IC-weighted:   rho = +0.964  (P < 0.001)
    Standard vs semantic:      rho = +0.491  (P = 0.125)
    IC-weighted vs semantic:   rho = +0.482  (P = 0.133)

The high standard-IC correlation confirms that IC-weighting is a consistent
enhancement.  The lower standard-semantic correlation indicates that
semantic purity captures a complementary notion of functional coherence.

Supplementary Note S1: Persistent Homology Analysis Details

For each embedding method, persistent homology was computed using the Ripser library with Vietoris-Rips complexes up to the maximum pairwise distance in the point set. Persistence diagrams were computed in dimensions H0 (connected components) and H1 (loops).

Topological consistency score definition: Let E = {e_1, e_2, ...} denote the set of all birth and death radii of finite topological features across H0 and H1. Let dp/dr be the gradient of functional purity with respect to distance threshold r, evaluated at the sampled grid points. The topological consistency score is defined as:

    C = (1/|E|) * sum_{e_i in E} |dp/dr|_{r = r_nearest(e_i)}

where r_nearest(e_i) is the nearest sampled r-value to event e_i. This score quantifies the average magnitude of functional purity change at topological transition points (birth/death of connected components and loops).

H1-only consistency score is computed identically but restricted to H1 events only.

Human network topological analysis used 2,000-node subsamples (seed = 42) matched to the G-F Score computation, with r in [0.05, 0.30].


Supplementary Note S2: Relationship Between G-F Score and Graph Community Detection

To ensure an apples-to-apples comparison, we compute the community-detection
baseline with FOUR algorithms on the curated 153-node yeast STRING network,
all using the identical purity formula (most-common GO term / total GO terms)
employed throughout the G-F pipeline:

    greedy_modularity_communities : 0.128   <-- same algorithm as the G-F curve
    Leiden (igraph)               : 0.180
    Louvain (igraph)              : 0.180
    label_propagation             : 0.182

Methodological note. The G-F purity curve in the main pipeline is built with
greedy_modularity_communities (utils.compute_gf_curve). Comparing an embedding
G-F Score (greedy_modularity) against a Leiden baseline conflates two factors:
the spatial-graph sweep versus a single PPI partition, AND the clustering
algorithm. The fair, like-for-like comparison therefore uses the
greedy_modularity baseline (0.128): the best 2D embedding (Spectral, 0.163;
UMAP-adjacency, 0.177) EXCEEDS this baseline. The higher Leiden/Louvain values
(0.180) reflect a stronger clustering algorithm finding a better single-scale
partition, not a stronger baseline signal; the Step 44 ablation confirms the
cross-method ranking is stable across all five algorithms (Kendall W = 0.797,
Spectral first under 4 of 5).

The G-F Score and single-partition community detection also measure
fundamentally different quantities. Leiden produces one partition optimised
for modularity; its purity is the best achievable at a single scale. The G-F
Score integrates purity over a continuous range of distance thresholds
[r_min, r_max], which is a strictly more demanding metric: an embedding must
maintain functional coherence at ALL scales simultaneously, not just at one
optimal resolution.

The 2D constraint is an additional consideration. All 11 embedding methods in
our primary comparison produce 2-dimensional coordinates, which necessarily
discards information present in the full network topology. Community detection
operates directly on the graph with no dimensional reduction.

Three lines of evidence show that the G-F framework provides value beyond what graph community detection alone can offer:

  (1) Higher-dimensional embeddings surpass the topological baseline for
      downstream tasks. Spectral embeddings at d=256 achieve function
      prediction MRR = 0.230, exceeding the PPI-topology baseline of
      0.219 (Phase 18 dimension sweep). The 2D G-F Score is a diagnostic
      and comparative tool, not a ceiling on embedding utility.

  (2) The embedding coordinate space enables cross-method comparison in
      a shared geometric framework. Community detection produces a partition,
      not a coordinate system; it cannot be directly compared with MDS,
      t-SNE, UMAP, or GNN embeddings. The G-F Score provides a common metric
      for evaluating how well ANY coordinate representation preserves
      functional structure.

  (3) "Functional dark matter" (Phase 11) is by definition invisible to
      graph community detection: these are protein pairs at distance >= 5
      hops in the STRING network, where no graph-based method can detect
      functional associations. The embedding geometry reveals 44 such
      pairs with extraordinary GO enrichment (retrograde transport 1809x,
      transmembrane transport 960x), demonstrating that the coordinate
      space captures functional signals beyond what topology alone encodes.

In summary, the G-F Score is not designed to outperform graph community detection at its own task (finding the single best partition). Rather, it provides a multi-scale, coordinate-space assessment that enables method comparison, dimensional analysis, and the discovery of functional associations invisible to topology.


Supplementary Note S3: Community Detection Algorithm Across Species

The primary G-F analysis uses greedy modularity optimisation (Newman 2004) as the community detection algorithm for yeast, human, and E. coli networks. For the Drosophila network (6,909 annotated nodes, ~90,000 edges after annotation filtering), greedy modularity optimisation becomes computationally prohibitive at each radius threshold, and connected_components is used instead.

To assess whether this choice affects cross-species comparisons, we performed a community detection ablation (Step 44) testing five algorithms on the yeast network: greedy modularity, label propagation, connected components, Louvain, and Leiden. Kendall's coefficient of concordance for method rankings across the five algorithms was W = 0.797, with Spectral ranking first under four of the five algorithms. This demonstrates that the cross-method ranking is robust to the choice of community detection algorithm.

For the human network, early validation (Phase 2) used the Louvain algorithm. In Phase 9, the analysis was unified to use greedy modularity, matching the yeast and E. coli analyses. The early Louvain-based human results are retained in the codebase for reproducibility but are marked as deprecated in the results files.

The community detection ablation confirms that the choice between greedy modularity and connected components does not qualitatively change the method rankings. The Drosophila results (Spectral #1, GF = 0.619) are therefore comparable to the other four species despite the different community detection algorithm.


Supplementary Note S4: Mechanistic Basis for Functional Dark Matter Pairs

Functional dark matter pairs are protein associations that are invisible to network topology (STRING distance >= 5 hops or not connected at score >= 700) yet geometrically proximate in the embedding space. We provide mechanistic explanations for the three literature-validated pairs.

NSG1 and NSG2 (Neuropeptide Signalling Genes). These are yeast homologs of the mammalian Insulin-Induced Gene (INSIG) family, involved in sterol biosynthesis regulation (Flury et al. 2005, EMBO J). Despite their functional homology, NSG1 and NSG2 share no direct protein-protein interaction in STRING and are separated by >= 5 hops in the network. The spectral embedding places them in geometric proximity because both participate in the same GO biological processes (sterol biosynthetic process, retrograde transport) and have similar interaction neighbourhood profiles — they each interact with proteins in the ER-associated degradation (ERAD) pathway, creating indirect geometric attraction through shared functional context rather than direct physical interaction.

GON7 and SPT8 (SAGA Complex Subunits). GON7 is a subunit of the SAGA (Spt-Ada-Gcn5 acetyltransferase) transcriptional coactivator complex, and SPT8 is a core SAGA component involved in TBP binding (Wang et al. 2020, Nature). While both are SAGA subunits, STRING does not record a direct interaction between them at the >= 700 confidence threshold. The embedding places them in proximity because the spectral decomposition captures co-membership in the same macromolecular complex through shared interaction partners: both GON7 and SPT8 interact with SPT3, SPT7, and other SAGA subunits. This shared-partner structure creates a "functional echo" in the Laplacian eigenvectors that manifests as geometric closeness even without a direct edge.

BST1 and ADD37 (ERAD Pathway Cross-Species Conservation). BST1 (yeast) maps to DERL1 in the human orthology, and ADD37 maps to DERL3. In both human and mouse d=64 embeddings, DERL1 and DERL3 appear as mutual rank-4 neighbours — a direct cross-species geometric conservation of ERAD pathway organisation. The STRING network does not connect BST1 and ADD37 because they participate in parallel branches of the ERAD pathway (DERL1 mediates substrate retrotranslocation, DERL3 is involved in substrate recognition). Their geometric proximity reflects functional coordination within the same pathway, captured by the spectral embedding through their shared interaction partners in the ERAD machinery (Hrd1, Der1, Cdc48).

General principle. The spectral embedding captures second-order and higher-order neighbourhood structure through the eigenvectors of the normalised Laplacian. Two proteins with similar interaction profiles (i.e., similar rows of the adjacency matrix) will have similar spectral coordinates even if they are not directly connected. This is the mechanism by which functional dark matter emerges: proteins that are functionally related through shared pathway membership, complex co-membership, or parallel roles, but lack direct physical interactions in the STRING database, are nonetheless placed in geometric proximity by the spectral decomposition. The embedding space thus reveals functional associations that are encoded in the global network topology but invisible to local graph-based methods (shortest paths, community detection).


Supplementary Note S5: Computational Complexity of G-F Score

The G-F Score computation involves three main steps with the following asymptotic complexities for N nodes and m radius thresholds:

  (1) Pairwise distance matrix: O(N^2 d) where d is the embedding
      dimension. For 2D embeddings, this is O(N^2).

  (2) For each of the m thresholds:
      - Graph construction: O(N^2) edge enumeration
      - Community detection (greedy modularity): O(N * E) in the worst
        case, where E is the number of edges at threshold r. For
        connected_components: O(N + E).
      - Purity computation: O(N * |T|) where |T| is the average number
        of GO terms per protein.

  (3) Trapezoidal integration: O(m).

Total complexity: O(m * (N^2 + N * E_max + N * |T|)) where E_max is the maximum edge count across all thresholds. For the curated yeast network (N = 153, m = 25), this takes approximately 2 seconds. For larger networks (N = 6,909 for Drosophila), the bottleneck is the greedy modularity step, motivating the use of connected_components for large N.

The distance matrix computation dominates for large N and is easily parallelisable. The community detection step is inherently sequential at each threshold but independent across thresholds, enabling parallel computation of different radii.

Scalability: For N = 10,000 nodes with m = 50 thresholds, the estimated wall-clock time is approximately 30 minutes using greedy modularity, or 2 minutes using connected_components. For genome-scale networks (N > 50,000), subsampling strategies (as used for the human and Drosophila analyses with 2,000-node samples) provide a practical approach while preserving ranking consistency.


Supplementary Note S6: Partial Correlation Analysis of G-F Score with Downstream Tasks

The Spearman correlations between G-F Score and downstream task performance (link prediction AUC: rho = +0.591, p = 0.056; kNN micro-F1: rho = +0.609, p = 0.047; function prediction MRR: rho = +0.645, p = 0.032; n = 11 methods) could potentially be driven by shared dependence on embedding effective rank or GNN architecture. We address this concern via partial Spearman correlations controlling for two confounders: effective rank (continuous, from SVD participation ratio) and GNN indicator (binary).

Effective rank is strongly correlated with G-F Score (rho = +0.873, p < 0.001) and moderately correlated with all downstream metrics (AUC: rho = +0.655; F1: rho = +0.627; MRR: rho = +0.527), confirming it as a potential confounder.

After controlling for effective rank:
  - GF vs Link Pred AUC: partial rho = +0.300 (p = 0.400, 49% attenuation)
  - GF vs kNN F1: partial rho = +0.291 (p = 0.415, 52% attenuation)
  - GF vs MRR: partial rho = +0.500 (p = 0.141, 23% attenuation)

After controlling for both effective rank and GNN indicator:
  - GF vs Link Pred AUC: partial rho = +0.318 (p = 0.404, 46% attenuation)
  - GF vs kNN F1: partial rho = +0.173 (p = 0.657, 72% attenuation)
  - GF vs MRR: partial rho = +0.582 (p = 0.100, 10% attenuation)

The GF Score -- MRR correlation is the most robust to confounding, retaining 90% of its original magnitude after controlling for both effective rank and GNN architecture. This suggests that the link between G-F Score and function prediction performance captures a genuine geometric-functional signal, not merely a shared dependence on embedding dimensionality. The GF-AUC and GF-F1 correlations are more substantially attenuated (46-72%), indicating that effective rank is a shared driver. This is expected: both effective rank and downstream metrics benefit from embeddings that spread information across dimensions.

Given the small sample size (n = 11), all correlations should be interpreted as exploratory. The GF-MRR correlation is the most defensible as a genuine association between geometric-functional consistency and downstream utility.


Supplementary Note S7: Dimension Sensitivity and the 2D Comparison

The primary G-F Score comparison uses 2-dimensional embeddings for all 11 methods. We chose 2D as the primary comparison dimension for three reasons:

  (1) Fairness: all methods are evaluated at the same dimension, avoiding
      the confound of comparing a 2D spectral embedding against a 128D
      GNN embedding. This isolates the geometric-functional signal from
      the dimensionality effect.

  (2) Interpretability: 2D embeddings can be visualised and inspected,
      enabling direct comparison of how each method organises the
      coordinate space.

  (3) Established precedent: most embedding comparison studies in the
      network science literature evaluate methods at a common low
      dimension (d = 2 to 16).

The reviewer rightly notes that 2D may systematically disadvantage methods designed for higher dimensions (GNNs, graph transformer PEs). We address this concern with the following evidence:

Existing high-dimensional data. The pipeline already includes extensive dimension sweeps for key methods:
  - Spectral: d = 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024 (Steps 47, 52-55, 66).
    G-F Score increases monotonically with d; function-prediction MRR
    rises to a peak at d = 512 (MRR = 0.244, exceeding the PPI-topology
    baseline of 0.219, first surpassed at d = 256 where MRR = 0.230).
    Beyond the peak MRR declines (d = 1024 -> 0.208), consistent with a
    bias-variance trade-off in the downstream KNN classifier rather than
    a failure of the embedding.
  - GAT: d = 2, 4, 8, 16, 32 (Phase 5B). G-F Score remains near-random
    (0.07-0.11) across all dimensions, confirming that the collapse is
    architectural (Proposition 1: attention degeneration), not a 2D
    bottleneck effect.
  - GraphSAGE: d = 2, 4, 8, 16, 32 (Phase 5B). G-F Score increases
    modestly with dimension but remains below Spectral at d = 2.
  - SignNet, RWPE, Laplacian PE: d = 2 to 32 (Step 64). All graph
    transformer position encodings yield GF Scores at or below Spectral
    across all tested dimensions.

These results demonstrate that the two key findings — spectral optimality and GAT collapse — are dimension-independent. Increasing d does not rescue GAT, and Spectral's G-F Score improves monotonically with d.

ProNE and HARP below random. ProNE (spectral propagation + Chebyshev approximation) and HARP (hierarchical graph coarsening) both score below the random baseline at d = 2 (ProNE GF = 0.087, HARP GF = 0.114 vs random 0.135). These methods are designed for higher dimensions, and their below-random performance at d = 2 could indeed be a dimension artefact. However, this does not affect the primary comparison because: (a) ProNE and HARP are supplementary methods added as robustness checks, not core comparison methods; (b) their low G-F Scores at d = 2 are consistent with their fundamentally different approach (Chebyshev approximation / hierarchical coarsening) not preserving the local distance structure that the G-F Score measures.

Future work. A full all-18-method × all-dimension sweep (d = 2, 8, 16, 32, 64) would provide the definitive answer but requires approximately 90 additional embedding computations and G-F Score evaluations. The pipeline supports this analysis via the dimension parameter in pipeline_config.yaml. We have prioritised the most informative subsets (Spectral gradient, GAT/GraphSAGE collapse test, PE comparison) for the current manuscript.
